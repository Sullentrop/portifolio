# Portfólio Pessoal - Maria Clara Sullentrop

Este é um projeto de **Portfólio Web** desenvolvido durante o curso de **Desenvolvimento de Sistemas** no SENAI. A página foi criada para apresentar informações de perfil profissional, habilidades técnicas, tabela com projetos recentes e um formulário funcional para contato.

---

## 📌 Sobre o Projeto

O objetivo principal deste projeto é aplicar conceitos fundamentais de desenvolvimento web, utilizando HTML5 semântico para garantir uma estruturação acessível e bem organizada.

### 🎯 Funcionalidades
- **Navegação Semântica:** Menu com ancoragem para navegação suave entre as seções (`Sobre`, `Projetos` e `Contato`).
- **Seção Sobre Mim:** Apresentação pessoal, imagem de perfil e resumo de competências.
- **Tabela de Projetos:** Organização dos trabalhos com nome, tecnologias utilizadas, status atual e links para visualização.
- **Formulário de Contato:** Formulário completo utilizando tags como `<fieldset>`, `<legend>`, `<select>` e `<textarea>`.
- **Rodapé:** Informações institucionais e links diretos para e-mail (`mailto:`) e telefone (`tel:`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Marcação e estrutura semântica)
- **CSS3** (Estilização e layouts responsivos)
- **JavaScript** (Lógica de interação)
